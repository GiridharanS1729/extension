

### 🎨 **CareBreak** (`care-break/`)
**Wellness & Health Reminder Extension**

A Chrome Extension that promotes healthier work habits through:
- ⏰ Posture reminders with funny Tamil audio alerts
- 💧 Water drinking reminders with Tamil songs
- 🔔 Notifications with audio control
- **Tech Stack**: HTML, CSS, JavaScript, Chrome Extension APIs (Manifest V3)

### 📊 **Claude Counter** (`claude-counter/`)
**Claude.ai Token & Usage Tracker**

A minimal extension that displays:
- Token count for conversations (with progress bar against 200k limit)
- Cache timer showing how long conversation remains cached
- Session (5-hour) and weekly (7-day) usage bars with reset countdowns
- **Features**: Privacy-focused (all local), intercepts API responses, vendored tokenizer
- **Available for**: Chrome, Edge, Firefox, Userscript

### 🏠 **Giridharan New Tab** (`homescreen/`)
**Personalized Chrome New Tab Dashboard**

A fully-featured new tab replacement with:
- Full-screen scenic background with customization
- Glassmorphism profile card
- Live 12/24h clock with optional seconds
- Shortcuts grid (auto-seeded from Chrome's most-visited)
- Markdown-capable notes card with Edit/Preview toggle
- **Tech Stack**: Vanilla HTML/CSS/JS, Manifest V3, Chrome Storage API
- **Zero dependencies** — no build tool, no npm, runs directly
