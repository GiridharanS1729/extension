# TextSnip ✨

TextSnip helps you create and reuse dynamic text snippets with placeholders.

## ✅ Features
- Dynamic placeholders like ${name}
- One-click usage
- Light / Dark theme
- Templates (Email, Code, Meeting, Todo)
- Usage stats & recent snippets

## 🚀 How to use
1. Click **+ New**
2. Write text with ${placeholders}
3. Save
4. Click **Use**, fill values, copy
